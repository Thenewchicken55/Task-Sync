# TaskSync

**TaskSync** is a simple task management app built with Next.js. It helps users manage their to-do list and visualize tasks on a calendar with a clean and intuitive UI.

## Features

- ✅ Add, delete, and complete tasks
- 🗓️ Drag and drop tasks to assign them to calendar dates
- 🧭 Responsive layout with a sidebar for tasks and a calendar view
- 🎨 Light theme with navy blue text and light blue accents
- 🔐 User login for saving tasks (in progress)

## Getting Started

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/tasksync.git
cd tasksync

# Install dependencies
npm install

# Start the development server
npm run dev
```
